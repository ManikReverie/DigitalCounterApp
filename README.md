# Digital Counter App

## Project Overview
A simple Android app developed using Kotlin and XML for the Veda Technology Android Development Track (Day 22). It features a counter with increment, decrement, and reset functionalities.

## Technologies Used
- Kotlin
- XML Layouts
- Android Studio

## Features
- Displays a large digital counter
- Increment (+) and Decrement (-) buttons
- Prevents the counter from going below zero
- Reset button to bring the count back to 0

## How to Run
1. Clone the repository. 2. Open in Android Studio. 3. Sync Gradle. 4. Run the app.

## Outcome
The application successfully updates the counter state dynamically based on button clicks and prevents negative values.
